# Life Coach ｜ 生活教练

一个从零开始的静态网页，展示“生活教练”日常工具版本的概念设计，包含状态感知、主动干预、思维工具、周期性总结与扩展性示例。

## 本地查看

1. 在仓库根目录运行一个本地服务器（任选其一）：
   - `python -m http.server 3000`
   - 或使用任意静态服务器工具。
2. 浏览器访问 http://localhost:3000 体验页面。

## 功能概览

- 状态感知：支持主动/被动/Coach 侧的信号清单。
- 高质量引导：根据状态与情绪生成即时提示和 life hack 建议。
- 思维工具：收录自用与通用的思维框架快速参考。
- 周期性总结：提供日/周/月的量化反思与目标记录占位。
- 扩展性：展示与闹钟、快捷指令、表格量化等常见工具的组合思路。
